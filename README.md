# SurgeLoom

A simple SurgeLoom Engine for Distributed architecture.

SurgeLoom is built to be simple and practical, focusing on doing one thing well.

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SurgeLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SurgeLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
